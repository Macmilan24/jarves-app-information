Data handling

Privacy notice

Effective 20 October 2026 · Support: samueldagne93@gmail.com

Purpose and access

Jarves is an invite-only operational assistant. It uses connected information to track work, identify email follow-ups, manage deadlines and provide reminders and reports. Access is limited to the invited Telegram user and approved Google account.

Information used

Account identity
Google email address and verified account identity, plus the invited Telegram account and chat identifiers.
Gmail
Message text and metadata, including senders, recipients, subjects, timestamps and thread identifiers. The connection permits read-only Gmail access; application filters and review limits select the threads processed.
Google Sheets
The assistant's task tracker and supported edits to its work records. Google's requested Sheets permission is broader than this individual tracker.
Google Tasks
A dedicated oversight list and supported task changes. Google's requested Tasks permission is broader than this individual list.
Google Calendar
Calendars created by the app and the reminder events they contain.
Conversations
Text requests, voice notes and transcripts, preferences, notes, recorded work and relevant conversation context.
Operational records
Assignments, owners, due dates, completion reports, verification, authorization renewals, synchronization state and delivery records.

Where information is processed

Google provides the connected email, spreadsheet, task and calendar services. Telegram carries assistant messages, voice notes, replies and reminders. The operator's configured server stores assistant records and runs the workflows.

Voice transcription runs on the configured assistant server. AI processing can use a local model or a hosted service. When hosted processing is enabled, relevant message text and operational context can be sent to OpenRouter and the model provider serving the request. The operator must disclose the selected provider and its data-handling settings before enabling that processing for the connected account.

Jarves uses these services to provide the requested assistant features. The application does not sell Google user data or use it for advertising. Use of information received from Google APIs must comply with the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

Assistant work records, conversation state, connection credentials and delivery information are retained on the configured assistant installation so tasks and follow-ups can continue across conversations and restarts. These records remain until removed by the operator; contact support to request deletion.

Successful workflow execution payloads are not retained. Failed execution payloads can contain email thread content and are configured for automatic cleanup after 72 hours. Relevant content can also appear in AI request context, where the selected provider's handling practices apply.

Encrypted backups can retain earlier copies after a record changes or is removed. Backups are currently removed by the operator rather than by an automatic retention schedule. A deletion request must address retained backup copies as well as the active assistant records.

Your controls

You can review or revoke Jarves's connection in your Google account connections. Revocation stops future authorized Google API access after currently valid credentials cease to work; it does not automatically delete records already stored by Jarves or messages already delivered to Telegram.

Contact support to request disconnection, review or deletion of retained assistant data. Some actions require the operator to remove records and recoverable backup copies separately.

Questions and changes

Contact samueldagne93@gmail.com with privacy questions or data requests. This notice will be updated when the deployment's providers, permissions or handling practices change.
